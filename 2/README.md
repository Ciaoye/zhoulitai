# 《失去之后》工伤故事页

周立太数字档案馆消费层的滚动叙事页面。当前版本以 33 位当事人和 28 宗核心案件为范围，把人物身份、迁徙、伤情、伤残等级、事故类型与赔偿记录放进同一套连续动画。

## 页面结构

页面共 14 章：

1. 周立太与前两宗案件
2. 徐昌文双赔案
3. 彭刚中断臂案
4. 22 年案件时间线
5. 33 人总览
6. 原籍地图
7. 事故地地图
8. 原籍到事故地的迁徙
9. 33 人伤情合并
10. 伤残等级
11. 事故类型
12. 年份与获赔金额
13. 一双手的价格
14. 尾声

## 实现

- `index.html`：章节文本与页面骨架。
- `styles.css`：响应式滚动布局、视觉系统和像素动画。
- `app.js`：原生 SVG 渲染、人物状态转换、悬浮卡片与滚动控制。
- `story-data.js`：从档案数据生成的人物与案件数据，视觉改动不直接修改此文件。
- `../地点地图/map-data.js`：Natural Earth 1:110m 中国轮廓和地点资料；本页只使用地图轮廓。

人物始终复用同一批 SVG 节点。章节切换时，33 个像素人物在名录、地图、合并身体、伤残等级、事故类型和金额坐标系之间插值移动。截肢会直接省略相应肢体并用红色截面标记；尘肺标记肺部；截瘫使用轮椅；工亡者使用黑色十字；家属请求人携带黄色文件。

地图按经纬度投影 Natural Earth 轮廓，补绘台湾轮廓。相邻地点先做视觉聚合，人物绕聚合点排布，以避免珠三角和重庆密集点与人物重叠。悬停或键盘聚焦人物可查看档案卡。

## 本地预览

在工作区根目录启动静态服务器：

```powershell
python -m http.server 8123 --bind 127.0.0.1
```

打开：

`http://127.0.0.1:8123/%E6%B6%88%E8%B4%B9%E5%B1%82/%E5%B7%A5%E4%BC%A4%E6%95%85%E4%BA%8B/index.html`

## 数据边界

当前页面只统计 `story-data.js` 对应的数据集。金额、伤残等级、事故年份和地名存在缺失或多来源冲突时，页面保留“未载明”或并列口径，不用视觉推断补齐。正式公开前仍需逐条回到 `sourceLocators` 复核事实，并审定隐私与版权。
