# 1996—2026 关系时间线

消费层静态页面。入口：`index.html`。

## 内容来源

- `LLM wiki/wiki/core/timeline-zhou-litai.md`
- `LLM wiki/wiki/core/timeline-china-labor-rights.md`
- `LLM wiki/wiki/years/year-1996.md` 至 `year-2026.md`
- 对应案件、法律政策、事件与媒体来源页

## 内容口径

- 同一案件的事实、诉讼与结果尽量合并为一个节点；只有发生制度转折时才增加后续节点。
- 圆点的大小按「关键节点 / 出现在某条链上 / 普通节点」三档区分，颜色按案件 / 政策 / 媒体 / 事件四类区分。
- 时间轴为纵向滚动画布（约 108 px/年，桌面端），顶部泳道标签固定不随滚动；四条纵列用浅色色带区分。
- 十二条件关系链的彩色曲线默认全部显示（平滑曲线 + 链末箭头）；点击图例中某条链的名称可聚焦该链（其余链与节点淡出），再次点击恢复。
- 节点标签以 SVG 文字渲染，用字形描边光晕（paint-order stroke）保证压线可读，不用白底块；默认只标注链上节点与公共事件，「标注全部节点」开关可为每个节点补标签。
- 连线表示时间、议题或制度承接关系，不宣称单一案件构成法律变化的唯一原因。
- 资料状态直接沿用 Wiki 的未复核、口径冲突与自述标记。
- 页面不修改或回写 Wiki 与数据层。

## 本地预览

从项目根目录启动静态服务器（`_preview-server.js`，端口 8765），浏览 `/消费层/时间线/`。直接双击 HTML 时，页面本身可运行，但 Wiki 链接和中文资源路径在不同浏览器中的兼容性较差，建议使用静态服务器。

`_preview/` 目录内含 playwright 截图脚本 `shoot.py`，用于在改版后回归视觉（含桌面三段、聚焦单链、全标注、hover 与移动端）。运行前需要在 `/workspace/周立太/` 起一个 HTTP server（8765 端口），并确认 chromium 可执行文件路径。
